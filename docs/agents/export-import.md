# Export and import (#191)

Full reference, moved verbatim from AGENTS.md. The always-on rules for this area are summarised in AGENTS.md; this file holds the detail, the measurements and the history behind them.

- **The household's own backup.** Under E2EE the host cannot restore anything, so any member can download a plaintext ZIP of everything they can read, from the Household page (`DataTransferSettings`, `src/components/data-transfer-settings.tsx`). It is also how a household moves to a self-hosted instance or to a database in the other encryption mode. Design: `docs/superpowers/specs/2026-10-24-export-import-design.md`.
- **All in the browser, no route, no migration.** `src/lib/household-data/export-format.ts` is pure (files map in and out, zod-validated parse, `planImport`); `src/components/household-data/export-import.ts` does the ZIP (`fflate`), the PDF download and upload and the posts; the store exposes `exportHousehold`, `readImport`, `importHousehold`.
- **The format is versioned** (`manifest.json`, `EXPORT_VERSION = 1`); a newer version is refused, not guessed at. Adding an `Apartment` field needs nothing here as long as its schema default lets an older export validate. Changing the shape of `apartments.json`, `ratings.json` or `locations.json` means a new version and a reader for the old one.
- **Import only into an empty household** (no apartments, no locations), checked in the browser. Every row gets a new id, distances are remapped to the new location ids, and nothing is geocoded or measured again: **the import makes no outside call.** A rating from the importer's own user id is restored; everyone else's becomes a line in the importer's comment on that apartment, worded in the importer's language by the caller (`RatingLine`), with scores at 0 ("not rated") when the importer had not rated.
- **Imports count against `MAX_APARTMENTS` like any add, and spend no credit** (#413): they go through `POST /api/apartments`, which no longer charges, and make no outside call. Imported apartments keep their processed state. The section refuses up front when the cap is short. Reasoning in `docs/security-notes.md`.
