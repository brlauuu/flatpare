# Theme (#324)

Full reference, moved verbatim from AGENTS.md. The always-on rules for this area are summarised in AGENTS.md; this file holds the detail, the measurements and the history behind them.

- **One palette for the landing page and the app**, as hex tokens in `src/app/globals.css` (`:root` light, `.dark` dark). Design: `docs/superpowers/specs/2026-10-03-app-restyle-design.md`.
- **Frame vs dense.** Frame = 3px `border-frame` + a hard shadow (`shadow-frame`, `shadow-button`, `shadow-hero`): nav edge, cards, dialogs, menus, buttons, badges (2px), and standalone fields. Dense = 1px `border` (the default for every `border` utility), no shadow: table cells, list rows, fields in multi-field forms. `Input`, `Textarea` and `SelectTrigger` take `weight="dense" | "frame"`; default dense.
- **`theme-contrast.test.ts` reads `globals.css`** and fails if a text pair drops under 4.5:1 or a field edge under 3:1, in either theme. Change a colour and that test tells you whether it is legible. It also checks the `@media print` block, which restores the light palette under `.dark` so the recovery kit prints dark-on-white from dark mode.
- **Colours come from tokens, never Tailwind's palette** (`text-green-600` and friends): `success`, `warning`, `destructive`, `primary`, `secondary`. The one exception is the map's own colours in `src/lib/map/style.ts`, since map tiles do not follow the theme; the marks on top use tokens.
- **Headings** use the `title-page` / `title-section` utilities, not base styles (utilities win over `@layer base`). **Never combine `title-*` with `text-*`, `font-*`, `tracking-*` or `leading-*`**: `cn()` (`src/lib/utils.ts`) treats them as conflicting and keeps the later one, and outside `cn` the CSS emit order would decide.
- **`cn()` knows the theme's own utilities** (`extendTailwindMerge` in `src/lib/utils.ts`): `shadow-frame|button|pressed|hero` merge as box-shadows, so `shadow-none` on a Card reliably replaces the frame shadow. A new theme utility that overlaps a Tailwind group belongs there too.
- **Focus is full strength**: `ring-ring` (never `/50`), offset from buttons so it shows on a blue or yellow fill. The button press (`motion-safe:`) applies to the framed variants only, never ghost or link.
- **The encryption screens render inside `GateFrame`** (`src/components/crypto/gate-frame.tsx`, a leaf), which drops all decoration in print.
- **`src/components/ui/*` are edited shadcn files.** Re-running `npx shadcn add <component>` overwrites the restyle; re-apply it by hand. The Badge deliberately does not force uppercase: badges also show values, and uppercase turns `m²` into `M²`.
- **Before/after screenshots:** `npm run build && npm run capture:screens -- screens/<name>` (gitignored). Same throwaway database and invented data as `capture:hero`.
