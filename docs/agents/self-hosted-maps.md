# Self-hosted map data (#339)

Full reference, moved verbatim from AGENTS.md. The always-on rules for this area are summarised in AGENTS.md; this file holds the detail, the measurements and the history behind them.

- **`FLATPARE_MAPS=openfreemap|local` is the self-hoster's choice, made at installation.** `docker-entrypoint.sh` refuses to start the container until it is set, with a message naming both. In the app (`readMapMode`, `src/lib/map/map-config.ts`), **unset or empty means OpenFreeMap** — that is flatpare.com and a plain `npm run dev`; anything else throws `MapConfigError`. flatpare.com does not serve map data (decided after 0.18.0, which briefly did) and `scripts/vercel-build.mjs` downloads nothing.
- **`local` never contacts an outside service.** The map reads the one `.pmtiles` file in `FLATPARE_MAP_DIR` (default `maps/`, mounted read-only at `/app/maps` by `docker-compose.yml`), through the `pmtiles://` protocol, with label fonts from `public/map-fonts/`, and stays near the file's bounds (`maxBounds`, `panBounds`). Areas it does not cover show the grid and the marks. **No file, several files, or an unreadable one is said on the map page** (`NoLocalMap` in `household-map.tsx`, five languages), never a fallback to OpenFreeMap.
- **The choice is read per request on the server**: `src/app/(app)/map/page.tsx` (`force-dynamic`) calls `readMapSource()`, which scans the folder and reads the 127-byte PMTiles v3 header for bounds and centre (`parsePmtilesHeader`, no library), and hands the plain `MapSource` (`src/lib/map/local-map.ts`, a leaf) to `MapPageClient`. Adding or replacing the file needs a reload, not a restart. The browser never reads the variable.
- **`GET /map-data/<file>` serves the file** (`src/app/map-data/[file]/route.ts`): single byte ranges (`parseByteRange`), `HEAD`, an ETag from size and mtime, and a 404 for anything but the one file or when the mode is not `local`. `/map-data/` and `/map-fonts/` are excluded in the `src/proxy.ts` matcher: OpenStreetMap data and fonts, nothing of anyone's, and every range request would otherwise run `auth()`.
- **Getting a file**: `scripts/build-map.sh <geofabrik-region>` (Planetiler in Docker, as the invoking user) writes `maps/<region>.pmtiles`; `maps/README.md` explains it and links the ready-made Swiss file on the `map-data-2026-10-25` release, which the manual `Map data` workflow (`.github/workflows/map-data.yml`) builds. Both pin the same Planetiler digest and `--only_layers`; keep those in step with the layers `style.ts` draws.
- **Fonts**: only the European ranges of the three Noto Sans fonts are shipped (2.6 MB, licence in `public/map-fonts/OFL.txt`); MapLibre draws CJK locally. Glyphs load through the `flatpare-glyphs://` protocol, which answers an unshipped range with an empty set instead of a 404 — a 404 before the first load would count as a fatal map error.
- The data's licence requires the credit `© OpenMapTiles © OpenStreetMap contributors` (`SELF_ATTRIBUTION`); OpenFreeMap's TileJSON brings its own.
