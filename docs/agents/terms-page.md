# Terms page (#474)

Full reference, moved verbatim from AGENTS.md. The always-on rules for this area are summarised in AGENTS.md; this file holds the detail, the measurements and the history behind them.

- **`/terms` is the terms and privacy page for flatpare.com**: who runs it, what is sold, who sells it (Stripe as merchant of record, #241), refunds, the data the server holds and why, who processes data, account deletion, use, liability, changes, Swiss law. Text in `src/content/terms.<locale>.md`, rendered like the guide; **English is binding**, and each translation says so. Decided by the owner on #474: a full refund within 14 days, no questions asked.
- **The operator is configuration** (`readOperator`, `src/lib/operator.ts`, a leaf): `FLATPARE_OPERATOR_NAME`, `FLATPARE_OPERATOR_CITY`, `FLATPARE_CONTACT_EMAIL`, so nothing personal is in the public repository. **With any of them unset there is no page (404) and no link**: a self-hosted copy must not name the flatpare.com operator or promise its refunds. `fillOperator` puts them into the text, Markdown and HTML taken literally.
- Public (`src/proxy.ts` passes `/terms` signed in or out) and outside the signed-in layout. Linked from the landing footer, the user menu, and the billing page ("By paying you accept the terms"), each only when the operator is set (`terms` props from the server components).
- **Keep it true.** It restates facts held elsewhere, and `terms-page.test.tsx` checks only the shape (the English outline, the placeholders, one price, the 14 days, no zero-knowledge or open-source claim, no ß). A new stored column about a person, a new outside service, a change to the price, the refund rule or the beta terms means editing all five files, together with the landing page's privacy section where it applies. The beta paragraph under "What you buy" goes at 1.0.0 with the other beta copy (#232). **The text promises that the app says so before a change takes effect**: a change of substance needs a one-time notice in the signed-in layout first, the way `UsageNotice` told members about the counts (#468).
- Not legal advice: the owner's draft, to be read by a lawyer before billing goes live.
